
# Sentiment Analysis for Product Reviews

This project performs sentiment analysis on Amazon product reviews using machine learning and NLP techniques.

## Project Structure

Sentiment Analysis for Product reviews/

├── Sentiment Analysis.ipynb

├── app.py

├── 1429_1.csv

├── Datafiniti_Amazon_Consumer_Reviews_of_Amazon_Products.csv

├── Datafiniti_Amazon_Consumer_Reviews_of_Amazon_Products_May19.csv

├── sentiment_model.pkl

├── tfidf_vectorizer.pkl

## Description

This project includes:
- Preprocessing of text data
- TF-IDF vectorization
- Training a machine learning model for sentiment classification
- Saving the model and vectorizer
- Optional deployment script using Flask or Streamlit

## How to Run

1. Clone the repository:
   git clone https://github.com/your-username/sentiment-analysis-reviews.git

2. Navigate into the project directory:
   cd sentiment-analysis-reviews

3. Install dependencies:
   pip install -r requirements.txt

4. Run the app (Flask):
   python app.py

   Or (Streamlit):
   streamlit run app.py
